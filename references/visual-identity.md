# Visual identity

`agent-loopkit` uses a neon systems-automation identity: dark infrastructure, cyan/blue loop arrows, circuit-grid depth, and clean developer-tool typography. The goal is to look like a polished open-source automation toolkit rather than a generic AI mascot.

## Core idea

**Signature motif:** a hexagonal loop mark with two circular arrows, orbit ticks, and a central signal node. It encodes recurring schedules, agent loops, and reusable playbooks.

The supplied final assets are raster-first marketing visuals. The repo keeps normalized PNG exports plus the original source JPGs for future recrops.

## Palette

| Token | Approx hex | Use |
|---|---:|---|
| Deep navy | `#030814` | Primary background |
| Electric blue | `#0877ff` | Left side of loop/logo gradient |
| Cyan glow | `#19e5ff` | Right side of loop/logo gradient |
| White | `#f7fbff` | Main title text |
| Muted blue-gray | `#8aa9c9` | Secondary/circuit detail |

## Assets

| File | Purpose |
|---|---|

| `assets/icon.png` | 256×256 small mark |

| `assets/banner.png` | 1280×640 README hero banner |
| `assets/banner-compact.png` | 1280×320 compact crop for narrower placements |
| `assets/social-preview.png` | 1280×640 GitHub social preview image |

## Usage

- Use `banner.png` at the top of `README.md`.
- Use `logo.png` as the GitHub repository avatar if uploading manually.
- Use `social-preview.png` under GitHub repository settings → Social preview.
- Use `banner-compact.png` only when a strict 4:1 banner slot is required.

## Notes

The light/checker logo source is preserved as `source-logo-light-checker.jpg`, but it is **not** used directly because the checkerboard appears to be baked into the image rather than true transparency.
